# 简易使用说明

观星工具，仅限版本（2026-10-31），仅限安卓，仅限官服（其他渠道服不保证一定能跑通）

当前版本**刚需模拟器**，不再刚需抓包，因为请求体被一次性密钥加密，而密钥使用非对称加密与服务器传输，无法仅通过抓包解密请求体获得存档。

之前抓包结果的 har 文件依旧可通过本工具解密。

## 安装python

[python.org](https://www.python.org) 官网选择任一大于等于 **3.10** 的版本。

安装时记得勾选 "Add Python to PATH"，方便直接在命令行调用。

## 安装依赖

必须安装依赖
如果第三方库下载较慢，请自行查询如何使用`-i `使用镜像下载

## 使用方法

### 快速启动

```batch
cd /d D:/yanyu-guanxing
python run.py
```

后续按照指引进行操作即可

### 抓包说明

1. 当前版本无法通过抓包文件直接解密存档，抓包文件目前只能获取部分 psw 。
2. 已收录的版本（当前为 00073570）无需抓包
3. 版本号变更时会自动抓取，也可以用 capture 抓包提供。
4. 安卓可使用免费开源抓包工具 ProxyPin ，请访问 [github官方仓库](https://github.com/wanghongenpin/proxypin) 的 releases 下载

抓包流程

1. 打开游戏，回到主界面
2. 打开 ProxyPin ，开启抓包（无需开启HTTPS代理）
3. 进入游戏，保存后，下载一次存档
4. 回到 ProxyPin ，停止抓包
5. proxypin 右上角三点 —— 视图导出 —— （新版本要选择HAR格式）
   模拟器需要配合MT管理器，将结果导出至文件系统，并在文件系统中复制到MuMu共享文件夹
   即，选中右侧界面，点左上角三横 —— MuMu共享文件，长按左侧 ProxyPinMM-DD_HH_MM_SS.har 文件，复制过去
   打开电脑的MuMu共享文件夹，一般在`C:\Users\xxx\Documents\MuMu共享文件夹`
6. 将导出的结果传输到电脑，然后启动程序`python run.py`进行解析

## 其他说明

1. 游戏本体版本更新后，密钥可能需要重新挖取。
2. 当前版本对于 iOS 不支持，有兴趣的可以 fork 之后在越狱的设备上自行修改项目。
3. 本项目本质自用工具，web 网页部分使用的是免费版作者的版本，一般不会更新，想使用其他工具，可以将本工具导出的 json 修正格式后自行导入网页的 localStorage 使用。
4. 本工具不涉及代码和游戏文件修改，免费不联网，仅供免费学习交流，倒狗biss。
5. 已重构项目，更换 keys.json 和 keys.local.json 格式；可以将新版工具下载后，将旧版文件复制进来，会自动更新。
6. 如果需要将工具打包分享，请自行去除 `output/` 、`web\local-save.js` 、`keys.local.json`、`keys.json.*.bak` 等文件，避免个人信息泄露。
7. 在assets文件夹中放入了未绑定账号版本的shute工具存档，[烟雨江湖shute（第六版）_未加密.zjs](assets/烟雨江湖shute%28第六版%29_未加密.zjs)，可直接导入自动精灵中使用。
8. 支持命令行子命令，运行 `python run.py -h` 查看用法（`capture` / `local` / `auto`）
